    V2.0 开发规划会议 - 2026-05-01

    参会者

    • kaluluosi

    议题

    1. 包管理迁移：poetry → uv

    决定：完全迁移到 uv

    原因： - uv 更快更现代 - 统一了包管理、虚拟环境、Python 版本管理 - 自带 uvx - 未来 AI MCP 开发常用工具

    方案： - Python 版本：3.12 - 删除 poetry.lock，清理 pyproject.toml - 使用 uv 重建依赖 - 清华镜像源不保留 - GitHub workflows 暂不改动，等迁移测试通过后再改

    2. 测试框架重构：unittest → pytest

    决定：完全重写测试

    原因： - unittest 老旧 - 当前测试强依赖真机，无法 CI 运行

    测试架构： 

    tests/
├── conftest.py              # fixtures
├── unit/
│   ├── test_models.py
│   ├── test_protocol.py     # mock socket
│   └── test_utils.py
├── service/
│   ├── test_host.py
│   └── test_local.py
└── plugins/
    ├── test_pm.py
    ├── test_cpu.py
    └── ...

    Mock 策略： - Protocol 层：mock StreamReader/StreamWriter - Service 层：mock Connection - 插件层：mock shell 输出

    pytest 依赖： - pytest - pytest-asyncio - pytest-mock - pydocstyle（文档检查）

    测试标记： - @pytest.mark.unit - 默认运行 - @pytest.mark.integration - 需要真机，默认跳过

    3. 文档注释完善

    决定：统一 Google 风格 docstring

    规范： 

    async def func(param: int) -> bool:
    """一句话描述。

    详细说明。

    等同于：adb 命令对照

    Args:
        param: 参数说明

    Returns:
        返回值说明

    Raises:
        SomeError: 异常说明

    Examples:
        >>> await func(1)
        True
    """

    优先级： - P0: device.py, service/host.py, service/local.py, plugins/pm.py - P1: 其他 plugins, protocol/ - P2: exceptions.py, models.py

    4. 连接复用优化

    问题：每次请求都创建新连接，效率低

    方案： - ADBClient：保持一个持久 host 连接 - Device：保持一个持久 transport 连接 - Service 基类添加连接管理：_get_connection(), _close_connection() - 自动重连机制 - asyncio.Lock 保证并发安全 - push/pull 等 sync 命令仍用独立连接（协议限制） - 添加显式关闭接口：ADBClient.close(), Device.close()

    兼容性：API 不变，内部改动透明

    5. 插件兼容性优化

    问题：CPU/Mem/Temp 等插件在部分设备/ROM 上失败

    策略：多层降级 → 默认值

    异常控制：参考 subprocess.run，添加 check=False 参数 - check=False（默认）：不抛异常，返回默认值 - check=True：失败时抛异常

    具体优化：

    插件 主方案 备用方案 默认值
    CPU 核心数 /sys/devices/system/cpu /proc/stat 1
    CPU 频率 /sys/.../cpufreq /proc/cpuinfo (1, 1, 1)
    CPU 使用率 /proc/stat top -n 1 CPUUsage(0)
    Mem 系统内存 /proc/meminfo - MemInfo(0, 0)
    Mem 应用内存 dumpsys meminfo /proc/<pid>/status MemStat()
    Temp 温度 dumpsys hardware_properties /sys/class/thermal/... dumpsys battery

    6. API 风格统一

    问题：property / async property / 方法混用，混乱

    决定：统一为 async 方法，移除所有 async property

    原因： - 所有操作都是 I/O 相关，都需要 await - await device.cpu.get_count() 比 await device.cpu.count 清晰 - 减少用户认知负担

    例外：纯计算、无 I/O 的可用 property（本库几乎没有）

    缓存：@alru_cache 保留，装饰在 async 方法上

    决策汇总

    事项 决定
    包管理 从 poetry 迁移到 uv + Python 3.12
    测试框架 从 unittest 换成 pytest + 完全重写 + mock
    文档注释 完善 Google 风格 docstring + pydocstyle
    连接复用 实现持久连接 + 自动重连
    插件兼容性 多层降级 + check=False 参数控制异常
    API 风格 统一为 async 方法，移除 async property
