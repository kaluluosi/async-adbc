# scrcpy 插件技术实现方案

## 1. 技术架构概述

### 1.1 整体架构
ScrcpyPlugin 将基于以下组件构建：

```
ScrcpyPlugin (主类)
├── init()              - 初始化方法
├── start()             - 启动 scrcpy 服务器
├── stop()              - 停止服务器
├── StreamReceiver      - 视频流接收类
├── InputController     - 输入控制类
└── utils               - 工具方法
```

### 1.2 关键技术点
- 使用 asyncio 进行异步网络通信
- 通过 ADB forward 进行端口转发
- 解析 scrcpy 协议格式
- 异步处理视频流数据

### 2.2 核心方法实现思路

#### init() 方法
1. 检查 scrcpy-server.jar 是否已存在
2. 如果不存在，从 vendor 目录推送到设备

#### start() 方法
1. 调用 init() 确保资源就绪
2. 设置端口转发：`adb forward tcp:{port} localabstract:scrcpy`
3. 在设备上启动服务器：`app_process /data/local/tmp scrcpy.Server ...`
4. 创建 socket 连接到转发的端口
5. 读取初始设备信息

## 3. scrcpy 协议分析

### 3.1 初始握手
1. 客户端连接后，服务器发送：
   - 1 字节: 设备名称长度
   - N 字节: 设备名称
   - 2 字节: 宽度 (大端)
   - 2 字节: 高度 (大端)

### 3.2 视频流格式
- 视频流是 H.264 编码的 NALU 单元流
- 每个数据包前有 6 字节头部：
  - 1 字节: 类型 (0x00 = 视频配置, 0x01 = 视频帧)
  - 8 字节: 时间戳 (可选，取决于配置)
  - 4 字节: 数据长度 (大端)

### 3.3 控制消息格式
发送给服务器的控制消息格式：
- 1 字节: 消息类型
- 可变长度: 消息内容

控制消息类型：
- `TYPE_INJECT_KEYCODE`: 注入按键事件
- `TYPE_INJECT_TEXT`: 注入文本
- `TYPE_INJECT_TOUCH_EVENT`: 注入触摸事件
- `TYPE_INJECT_SCROLL_EVENT`: 注入滚动事件
