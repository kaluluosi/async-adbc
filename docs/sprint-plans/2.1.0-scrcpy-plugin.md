## 1. 项目概述

### 1.1 背景
async-adbc 是一个纯 Python 异步 ADB 客户端实现。当前版本通过 minicap 插件提供高效的截图功能。为了进一步增强实时屏幕显示和控制能力，计划在 2.1.0 版本中添加 scrcpy 插件支持。

### 1.2 目标

- 支持输入控制（点击、滑动、键盘等）
- 与现有插件系统无缝集成
- 保持项目的异步特性和高性能

## 2. scrcpy 工作原理分析

### 2.1 scrcpy 简介
scrcpy 是一个开源工具，用于显示和控制 Android 设备。它通过 ADB 连接，提供低延迟的屏幕镜像和输入控制。

### 2.2 核心工作原理
1. **服务器端**: 在设备上运行 `scrcpy-server.jar`，负责:
   - 捕获屏幕帧（使用 MediaCodec 编码）
   - 接收并执行输入事件
   - 通过 socket 与客户端通信

2. **客户端**: 接收视频流并显示，发送输入事件

3. **通信流程**:
   - 客户端通过 ADB 推送并启动服务器
   - 建立 socket 连接（通常使用端口转发）
   - 双向传输视频流和控制命令

### 2.3 与 minicap 的对比
| 特性 | minicap | scrcpy |
|------|---------|--------|
| 主要功能 | 截图 | 实时视频流 + 输入控制 |
| 性能 | 单次截图 | 持续视频流 |
| 资源占用 | 较低 | 较高（编码视频流） |
| 输入控制 | 不支持 | 支持 |

### 3.1 架构设计

```

├── async_adbc/
│   ├── plugins/
│   │   └── scrcpy.py          # 新增: scrcpy 插件

│       └── scrcpy/            # 新增: scrcpy 二进制资源

```

### 3.2 核心功能模块
1. **初始化模块**: 推送和启动 scrcpy-server
2. **连接管理**: 建立和管理与服务器的 socket 连接
3. **视频流接收**: 异步接收 H.264 视频流
4. **输入控制**: 发送点击、滑动、键盘等事件
5. **工具方法**: 截图、录屏等便捷功能
