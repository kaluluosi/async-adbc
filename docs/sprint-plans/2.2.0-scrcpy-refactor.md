## 1. 项目背景与决策

### 1.1 问题回顾
1. **原始实现问题**: 之前的 scrcpy 插件实现存在协议兼容性问题
2. **pyscrcpy 集成尝试**: 尝试集成 pyscrcpy 库，但遇到依赖问题
   - pyscrcpy 依赖 `av` 包进行 H.264 解码
   - `av` 包在 Windows 上编译失败（Cython 版本不兼容）

### 1.2 技术决策
经过评估，决定采用以下方案：
1. **回到自己实现**，不依赖外部库
2. **参考 pyscrcpy，使用 scrcpy 1.20 协议**
3. **直接返回 H.264 字节流**，不进行解码，让用户根据需要选择解码方案

### 1.3 决策理由
1. **避免依赖问题**: 消除 `av` 等复杂依赖
2. **保持轻量**: async-adbc 应该保持轻量级
3. **灵活性**: 用户可以根据需要选择解码方案
   - 轻量使用: 直接处理字节流
   - 图像处理: 使用 OpenCV
   - 实时显示: 使用 PyAV 或 FFmpeg
4. **协议稳定性**: scrcpy 1.20 协议更稳定，社区支持更好

## 2. 技术架构设计

### 2.1 核心组件
```
ScrcpyPlugin (async_adbc/plugins/scrcpy.py)
├── init(): 推送 scrcpy-server.jar
├── start(): 启动服务器，建立连接
├── get_frame(): 获取 H.264 字节流
├── stream_frames(): 流式获取帧
├── tap()/swipe()/key()/text(): 输入控制
└── stop(): 停止连接
```

### 2.2 数据流
```
Android设备
    ↓ (ADB)
scrcpy-server.jar (运行在设备上)
    ↓ (socket)
ScrcpyPlugin (H.264 字节流)
    ↓ (可选解码)
用户应用
    ├─ 直接处理字节流
    ├─ 使用 OpenCV 解码
    └─ 使用 FFmpeg 解码
```

### 2.3 协议细节（基于 scrcpy 1.20）
1. **服务器启动命令**:
   ```bash
   CLASSPATH=/data/local/tmp/scrcpy-server.jar \
   app_process / com.genymobile.scrcpy.Server \
   1.20 \          # 版本
   info \          # 日志级别
   720 \           # 最大尺寸
   2000000 \       # 比特率
   15 \            # 最大 FPS
   -1 \            # 屏幕方向锁定
   true \          # 隧道转发
   - \             # 裁剪
   false \         # 发送帧率
   true \          # 控制启用
   0 \             # 显示 ID
   false \         # 显示触摸
   true \          # 保持唤醒
   - \             # 编解码器选项
   - \             # 编码器名称
   false           # 关闭屏幕
   ```

2. **握手协议**:
   ```
   客户端连接 → 接收 dummy byte (1字节) → 接收设备名称 (64字节，null终止)
            → 接收分辨率 (4字节，大端序，宽和高) → 开始接收视频流
   ```

3. **视频流格式**: H.264 编码的字节流
4. **控制协议**: 通过独立的控制 socket 发送二进制控制命令

## 4. API 设计

### 4.1 核心 API
```python
class ScrcpyPlugin:
    async def start(self, max_size=720, bit_rate=2000000, max_fps=15):
        """启动 scrcpy 连接"""
        
    async def stop(self):
        """停止 scrcpy 连接"""
        
    async def get_frame(self) -> Optional[bytes]:
        """获取一帧 H.264 编码数据"""
        
    async def stream_frames(self) -> AsyncGenerator[bytes, None]:
        """流式获取 H.264 帧"""
        
    async def tap(self, x: int, y: int):
        """点击坐标 (x, y)"""
        
    async def swipe(self, x1: int, y1: int, x2: int, y2: int, duration=0.3):
        """从 (x1, y1) 滑动到 (x2, y2)"""
        
    async def key(self, keycode: int):
        """发送按键事件"""
        
    async def text(self, text: str):
        """输入文本"""
```
