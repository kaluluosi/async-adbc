# async-adbc 2.2.0 开发计划
日期：2026-05-02
参会人员：煊哥、橙子

## 一、连接管理策略（已确认）
- 保持每个请求独立创建新连接，避免流式读取和短连接请求冲突
- 由接口函数自己管理 Response 的生命周期（比如 scrcpy 保存 Response 对象防止 GC）

## 二、删除 minicap 相关代码
minicap 在 1.0 版本是注释掉的，未正式发布，且对模拟器支持差，决定直接删除：
1. 删除 `async_adbc/plugins/minicap.py`
2. 删除 `async_adbc/vendor/minicap/` 目录
3. 从 `async_adbc/plugins/__init__.py` 移除 minicap 导入和导出
4. 从 `tests/integration/test_plugins.py` 移除 TestMinicapPluginIntegration 类
5. 从 README.md 移除 minicap 说明

## 三、Scrcpy 插件核心功能完善
目标：将 async-adbc 作为高性能安卓游戏自动化测试 MCP 的基础库
1. 新增 `screencap()` 方法：获取单张截图（支持保存到文件或返回 bytes）
2. 新增 `stream_frames()` 异步生成器：支持 `async for frame in device.scrcpy.stream_frames()` 迭代
3. 新增 `record()` 方法：录制视频到本地文件（mp4/mkv）
4. 完善测试用例：单元测试 + 集成测试

### Scrcpy 接口设计讨论
- 支持两种视频流读取方式：
  1. 异步后台任务 + 事件回调（`set_frame_callback()`）：适用于实时投屏 UI
  2. 异步生成器（`async for`）：适用于自动化测试循环截图识别

## 四、其他改进
1. 修复 bugfix 分支里的 ConnectionResetError 问题（如还有）
2. 更新文档：Scrcpy 插件使用说明
3. 更新版本号到 2.2.0
