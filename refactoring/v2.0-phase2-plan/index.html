    V2.0 第二轮开发计划

    概览

    第一轮已完成：模块拆分、插件注册表、兼容层。

    第二轮包含：uv 迁移、测试重构、文档完善、连接复用、插件优化、API 统一。

    阶段一：uv 迁移

    目标

    从 poetry 完全迁移到 uv，使用 Python 3.12

    任务清单

    • [ ] 删除 poetry.lock
    • [ ] 重写 pyproject.toml：
    • [ ] 移除 [tool.poetry] 配置
    • [ ] 使用标准 [project] 配置
    • [ ] 更新 [build-system]
    • [ ] 添加 [project.optional-dependencies]：
      • test: pytest, pytest-asyncio, pytest-mock, pydocstyle, coverage
      • docs: mkdocs, mkdocs-material
    • [ ] 用 uv sync 创建虚拟环境并验证
    • [ ] 更新 .gitignore 添加 uv 相关
    • [ ] 提交
